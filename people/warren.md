# Warren

Researcher focused on novel methods of loss and sample efficiency. Currently *not* doing post-training work. Met Kian at the opera (2026-03-14).

## Research takes

- View: when the model correctly gets the token, the update is essentially wasted. The update needs to be stronger.
- Proposes changing the pre-training token objective to *not* be next-token prediction based.
- "Reward with Warren" — rough thread in the same vein as: assigning reward to RL tasks and calculating rewards is currently inefficient.
- Mentioned using RL for Renjie poker.

## Conceptual

- Frames LLM as a representation of some sparse higher-dim space.
  - Perplexity counter: "The LLM is really just a nonlinear map over a finite-dim dense space; the high-dim sparse space only shows up when you impose a sparse feature or sparse-weight representation on top."
